# Решатель головоломки с перемещением фигур

Программа предназначена для поиска последовательности перемещений фигур на прямоугольном поле, чтобы удовлетворить заданным условиям на конечное положение некоторых из них. Головоломка аналогична классическим «пятнашкам», но фигуры могут быть произвольной формы и перемещаются как единое целое, сохраняя взаимное расположение составляющих их клеток.

## Формат входных данных

Входные данные подаются в текстовом файле (или со стандартного ввода) следующей структуры:

```
<число строк M> <число столбцов N>
<поле>
<число фигур, для которых задана конечная позиция>
<M строк по N символов>
```


### Описание полей

- **`<число строк>`**, **`<число столбцов>`** — размеры игрового поля (целые положительные числа).
- **`<поле>`** — матрица размером `строки × столбцы`, состоящая из символов:
  - заглавные латинские буквы (`A`–`Z`) — клетки, принадлежащие фигурам;
  - символ `#` — пустая клетка.
  Все клетки с одинаковой буквой считаются одной фигурой. При этом фигура является связной.
- **`<число фигур, ...>`** — количество фигур, для которых указано требуемое конечное положение (целое неотрицательное число).
- Далее для каждой такой фигуры задаётся строка:  
  **`<координаты>`** **`<буква>`**  
  где `<координаты>` — два целых числа (номер строки и номер столбца, начиная с **1**), задающие положение **первого элементарного квадратика из первой строки фигуры** (см. пояснение ниже), а `<буква>` — заглавная латинская буква, идентифицирующая фигуру.


## Выходные данные

Программа выводит в стандартный поток вывода:

- Если решение существует — последовательность ходов, описывающая перемещение фигур. Формат каждого хода:
  `<буква> <направление>`, где `<направление>` — одно из: `U` (вверх), `D` (вниз), `L` (влево), `R` (вправо).
- Если решения не существует — сообщение `No solution`.


### Пример

```
5 4
ABBC
ABBC
DEEF
DGHF
I##J
1
4 2 B
```

Здесь:
- Поле размером 5×4.
- Фигура `B` представляет собой квадрат 2×2 (клетки (1,2), (1,3), (2,2), (2,3)).
- Требуется, чтобы фигура `B` переместилась так, чтобы её опорная точка (первый квадратик первой строки) оказалась в клетке (4,2). То есть сам квадрат должен занять позицию с верхним левым углом в (4,2), т.е. клетки (4,2), (4,3), (5,2), (5,3).


## Использование

Программа читает входные данные из файла, имя которого передаётся единственным аргументом командной строки:

```
./PischenkoR_131_project.exe input.txt
```

Если аргумент не указан, чтение производится из стандартного ввода.
